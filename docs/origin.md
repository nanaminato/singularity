# 来源与演进

2026-11-14，用户明确提出：奇点应描述如何构建 LittleLoop 这样的认知系统，而非充当认知系统的数据存储；应丰富系统描述能力，并随着项目发展持续优化奇点架构。用户随后批准先完成模型规范、迁移方案和核心实现，再用 LittleLoop 验证，并明确无需保留旧数据与历史兼容。

0.4 因此采用统一节点、关系、引用与树视图，并拆分授权、交付、验证状态。此前 Markdown/TOML 记录和两个虚构场景不再是当前模型入口。当前规范见 [SPEC](../SPEC.md)，重建边界见 [迁移方案](migration.md)。

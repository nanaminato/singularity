# 来源与取舍

来源：[奇点驱动 Agent 开发分享对话](https://chatgpt.com/share/6abcc255-60d0-83e9-8752-e24bc93d1f52)。于 2026-09-30 读取。

这一版采用对话最后一轮的范围：

- 独立协议仓库，先做 0.1 Protocol。
- 10 条 Meta Singularities，推导 SPEC 和操作约定。
- 6 个基础概念，不增加庞大的需求字段。
- 目标项目保存短入口、版本配置和自己的意图。
- 一个奇点是逻辑单位，不强制一奇点一文件。
- Region 可选；以最小上下文和任务驱动发现支持局部接入。
- 发现的是 Candidate，显式人的意图才能确认。

较早讨论中的逐文件 core 目录、完整项目扫描或引擎设想没有作为本版默认设计。数据库、CLI、Engine 和 Agent 留待实验结果支持后再开发。

## 推导出来的具体选择

Markdown 字段标签、记录目录、状态名称、版本标签以及示例布局都是当前推导决策，不应提升为永久的人类奇点。元奇点的初始 Candidate 状态见 [D-PROTOCOL-002](../.singularity/decisions/protocol.md)。

两个示例没有复制 RelaxKonOS 或其他真实项目的业务要求。PAM 场景只是取自对话的教学素材，没有真实代码核查，也不是通用安全设计建议。

本仓库不是完整聊天存档，只保存实现协议所需的来源链接和取舍。当前没有替用户选择开源许可证；在分发权限方面按仓库实际声明处理。

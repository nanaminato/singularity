# Roadmap

| 阶段 | 内容 | 进入下一阶段的依据 |
| --- | --- | --- |
| 0.1 Protocol（当前 Draft） | Markdown、元奇点、Agent 入口、模板、两个示例 | 真实任务证明协议可理解、人工负担可控、变更可追溯 |
| 0.2 Tooling（计划） | init / validate 等导入与结构工具 | 有重复且明确的手工成本；稳定的格式约定 |
| 0.3 Engine（计划） | 图关系、上下文检索、影响分析 | 局部理解与跨边界实验表明自动化有益 |
| 1.0 Agent（计划） | 协议执行者与现有 Coding Agent 协作 | 协议和工具已验证，确有独立执行层的必要 |

当前没有自动提取、语义冲突检测、CLI 或 MCP 服务。未来工具应保持 Markdown 可读、Git 可追溯、意图与实现分离、局部接入及明确人的控制。

先确认或修订元奇点、运行 [实验](experiments.md)，再增加机制。数量级与代码覆盖率不作为协议成功标准。

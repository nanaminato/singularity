# Roadmap

| 阶段 | 内容 | 进入下一阶段的依据 |
| --- | --- | --- |
| 0.3 Protocol（当前草案） | TOML、CLI、Angular 编辑器、Agent 入口与两个示例 | 在真实项目中验证记录格式与协作流程 |
| 后续 Engine | 图关系与跨边界影响分析 | 局部理解与跨边界实验表明自动化有益 |
| 1.0 Agent（计划） | 协议执行者与现有 Coding Agent 协作 | 协议和工具已验证，确有独立执行层的必要 |

本地 CLI 和网页共用版本化 TOML 记录，操作说明见 [工具文档](../tools/README.md)。Git 保留变更历史，Markdown 承载协议、推导和示例说明。自动提取、语义冲突检测和 MCP 服务仍属后续议题。

先确认或修订元奇点、运行 [实验](experiments.md)，再增加机制。数量级与代码覆盖率不作为协议成功标准。

## Singularity project model

Read `.singularity/README.md` and the configured protocol specification as needed.
Use the configured format 3 CLI to inspect nodes, bounded context, tree views and impact.
Only explicit human-confirmed intent is authoritative. Existing files are evidence.
Keep authorization, delivery and verification separate; do not claim planned work is implemented.
Use shared apply transactions with the expected revision; include actual authorization basis for protected changes.
The model may be incomplete. Check relevant code and documents rather than assuming missing graph edges mean no dependency.
Record concrete expression problems and improve the model in response to project development.

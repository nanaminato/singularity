# Meta Singularities

Status: Proposed baseline for 0.1.0

以下十条取自来源对话最后一轮的公理建议。初始状态均为 Candidate，等待人的明确确认或修改；这一版规范从它们推导为 Draft。ID 稳定，单文件归组。不为当前实现选型额外创造公理。

## MS-001

Status: Candidate

Statement: A singularity represents human intent that cannot be safely derived by an agent.

## MS-002

Status: Candidate

Statement: Information that can be safely derived should not become a singularity.

## MS-003

Status: Candidate

Statement: Confirmed singularities are authoritative.

## MS-004

Status: Candidate

Statement: An agent must not silently change the meaning of a confirmed singularity.

## MS-005

Status: Candidate

Statement: Existing code is evidence, not automatically intent.

## MS-006

Status: Candidate

Statement: A contradiction between confirmed singularities must be exposed to the human.

## MS-007

Status: Candidate

Statement: Singularity adoption is incremental.

## MS-008

Status: Candidate

Statement: An agent should use the minimum project context necessary for the current task.

## MS-009

Status: Candidate

Statement: Unmodeled regions of a project are valid and expected.

## MS-010

Status: Candidate

Statement: Changes to a singularity require reevaluation of its affected decisions and implementation.
